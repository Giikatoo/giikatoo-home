# เว็บไซต์โปรไฟล์ส่วนตัว

โปรเจกต์เริ่มต้นสำหรับเว็บไซต์แนะนำตัวและแสดงผลงาน พัฒนาด้วย HTML, CSS และ JavaScript โดยไม่ต้องติดตั้ง dependency เพื่อทดลองเปิดหน้าเว็บ

## เริ่มต้นใช้งาน

เปิด `index.html` ในเบราว์เซอร์ หรือใช้ส่วนขยาย **Live Server** ใน Visual Studio Code เพื่อดูการเปลี่ยนแปลงระหว่างพัฒนา

## โครงสร้างโปรเจกต์

- `index.html` — หน้าเว็บหลัก
- `assets/css/` — ไฟล์รูปแบบและการจัดหน้า
- `assets/js/` — JavaScript ที่หน้าเว็บโหลดใช้งาน
- `assets/images/` — รูปโปรไฟล์และภาพผลงาน (เพิ่มไฟล์เมื่อเริ่มใช้งาน)
- `src/` — ตัวอย่าง TypeScript ซึ่งยังไม่ได้เชื่อมกับหน้าเว็บ
- `docs/FEATURE-PLAN.md` — แผนฟีเจอร์ เครื่องมือ และแนวทางสำหรับผู้เริ่มต้น

## ขอบเขตปัจจุบัน

หน้าเว็บยังเป็น starter ตัวอย่าง ยังไม่มีแกลเลอรีจริง แบบฟอร์มส่งข้อความ หรือกล่องจดหมายหลังบ้าน โปรดดูแผนงานและข้อควรระวังด้านข้อมูลส่วนตัวในเอกสาร
